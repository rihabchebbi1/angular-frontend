# Angular Frontend

## 📌 Overview

This repository contains the frontend of a web application developed using Angular and TypeScript.

## 🛠️ Technologies

- **Angular** — Frontend framework
- **TypeScript** — Application development
- **HTML & CSS** — Structure and styling
- **npm** — Package management

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/rihabchebbi1/angular-frontend.git
```

Navigate to the project directory:

```bash
cd angular-frontend
```

Install dependencies:

```bash
npm install
```

### Run the Application

Start the development server using the script configured in `package.json`:

```bash
npm start
```

If `npm start` is not configured, use the Angular CLI command:

```bash
npx ng serve
```

Then open the local URL displayed in your terminal.

## 📁 Project Structure

- `src/` — Application source files
- `angular.json` — Angular workspace configuration
- `package.json` — Project dependencies and scripts
- `tsconfig.json` — TypeScript configuration
